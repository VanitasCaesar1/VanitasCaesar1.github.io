Projects

Treato

One shared health record for families, doctors and clinics in India.
  • 4apps: patient, doctor, web, clinic desk
  • ~360database migrations
  • 1identity across patient, doctor and clinic
  • Mobile. Patient and doctor apps in React Native and Expo: booking, family records, in-app chat and LiveKit video visits.
  • Backend. The core API in Go (Fiber) on PostgreSQL: REST plus a read-only GraphQL layer, RabbitMQ between services.
  • Auth. A Rust service for phone OTP and passkeys.
  • AI. Maya, an LLM agent in Go with tool calling. It explains reports in plain words, keeps a health diary and drafts a brief before a visit.
  • Web and desktop. A Next.js website with a public doctor directory, and a Tauri app for clinic front desks: tokens, walk-ins, billing.

hoarding.top

Paid leaderboards for the world, your country and your city, where what you pay is your rank.
  • Anyone can put a card on the boards: a logo, a name and one link. The #1 of each board gets the billboard spot, and taking it costs $1 more than the card there now.
  • Under the boards is a free directory of apps, websites and open-source projects, built from public data.
  • Built end to end: Next.js, Convex on my own server, Razorpay payments with a review step, invoices and emails.

tabcn

46 animated tab bars and panels for Expo and React Native, in the style of shadcn/ui.
  • A small npm package, react-native-tabcn, handles the navigator, safe areas, the sliding highlight, badges and accessibility.
  • Each design is one file you copy in with the shadcn CLI, matched to a real app's screenshots and checked right to left and at the largest text size.

expo-hot-toast

The react-hot-toast API for Expo: Liquid Glass on iOS 26, Material 3 on Android, frosted glass on the web.
  • Every button on the demo site fires a real toast from the library, running in your browser.

hippo

Memory for AI coding agents. Every night it turns the day's repeated corrections into rules.
  • Reads the day's Claude Code, Codex and OpenCode sessions, turns repeated corrections into rules, and has a second model check each rule against what happened.

An arcade where coding agents publish browser games and get players' crashes back as reports they can fix.
  • Runs on Cloudflare Workers with D1 and R2.
