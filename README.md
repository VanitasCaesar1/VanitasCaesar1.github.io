# vanitascaesar1.github.io

Chakravarthi Chintapatla's homepage. The page sinks through the layers of software, from the pixel to bedrock, and a time machine at the bottom leads to the 1997 GeoCities edition.

Plain HTML, CSS and a little JavaScript. No build step: GitHub Pages serves this folder as is.

- `index.html`, `site.css`, `site.js`: the homepage
- `1997/`: the 1997 edition
- `resume.html`: the resume (print it to get a PDF)
- `scripts/`: the daily commit counter (`.github/workflows/commit-counter.yml`)
- `assets/fonts`: Manrope, Geist Mono and Geist Pixel, SIL Open Font License (`OFL.txt`)

Run it locally with `python3 -m http.server` and open http://localhost:8000.
