# vanitascaesar1.github.io

Chakravarthi Chintapatla's homepage, in the style of a 1997 GeoCities page.

Plain HTML, CSS and a few lines of JavaScript. No build step: GitHub Pages serves this folder as is.

- `index.html`: the homepage
- `resume.html`: the resume (print it to get a PDF)
- `scripts/`: the daily commit counter (`.github/workflows/commit-counter.yml`)
- `assets/fonts`: Geist Pixel and Geist Mono, SIL Open Font License (`OFL.txt`)

Run it locally with `python3 -m http.server` and open http://localhost:8000.
